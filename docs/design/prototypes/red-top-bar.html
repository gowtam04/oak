What is Garchomp’s base speed and what nature should I run?

Garchomp’s base Speed is 102.

Recommended nature: Jolly (or Adamant if you want more Attack power instead).

In Champions, Garchomp is typically built as a fast physical attacker. With 32 Speed Stat Points and a Jolly nature it reaches 169 Speed at Level 50 (fixed 31 IVs). Adamant is the main alternative if you prefer raw power over outspeeding.

Inference

⚑ high Jolly is the standard competitive choice for Garchomp’s speed tier in doubles. — Based on typical usage patterns for speed-focused sets.

Reasoning
Base 102 Speed is Garchomp’s identity stat. Jolly is +Speed −Sp. Atk, which Garchomp does not miss. Adamant is the trade if you are already outspeeding the relevant threats.
