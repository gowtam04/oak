## What Oak is (the brief these worlds answer)

Oak is a games assistant for Pokémon, not a franchise merch app. It reasons on top of data. Every answer has a lead, a deduction, citations, an uncertainty flag, and a generation. People swing between sweaty competitive work (calcs, usage, teams) and whole-game curiosity (locations, glitches, Mystery Dungeon). Guests can chat. Accounts unlock history and the team builder. There is voice, image input, an artifact viewer, and eleven scopes. The UI has to work as a desktop site and as an iOS (and later Android) client of the same product.

That is a hard object. It is not a landing page and not a Pokédex toy. The five worlds below take that object in five opposite directions.
